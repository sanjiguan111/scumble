This directory is the structured knowledge graph of scumble's architecture, design decisions, and test specs, managed by [lat.md](https://www.npmjs.com/package/lat.md). Install the `lat` command with `npm i -g lat.md` and run `lat --help`. Files in this directory:

- [[overview]] — what scumble is, package layout, the core principle
- [[architecture]] — retained tree + command stream, binary transport, build cache, group opacity/layer
- [[lynx-integration]] — Lynx runtime constraints and platform traps
- [[rendering]] — feature semantics (shapes, paint, paths, filters, text) and parity gaps
- [[animation]] — overlay model, frame drivers, playback control
- [[tests]] — test specifications (require code mentions)
